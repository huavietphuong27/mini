2. Register Document Hash

Select a file or enter text to compute a local SHA-256 hash. Duplicate hashes are rejected on-chain.

3. Verify / Lookup Document Hash

Prove whether a document hash was registered, by which address, and at what blockchain timestamp.

Enter or select a document to look up its on-chain timestamp record.

4. Revoke Record (Original Registrar Only)

Enforced in Solidity: only the address that originally registered the hash can revoke it.

5. Contract Owner Controls (Owner Address Only)

Non-owner accounts calling this action are rejected by the smart contract (Unauthorized: caller is not contract owner).
